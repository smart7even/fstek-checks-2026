# Методический документ: меры защиты информации в СПО

Вики-комплект по приказу ФСТЭК России от 11.04.2025 № 117 и специальному набору мер для СПО ГИС Санкт-Петербурга.

Документы привязаны к **специальному программному обеспечению**, а не к скриптам автопроверки Linux-хоста. Испытания выполняются в интерфейсе СПО (`example.ru/admin`, `example.ru/public`) и по журналу РСБ.

Нумерация мер начинается с **008 = ИАФ.1**.

## Источники

Два обязательных источника, в этом порядке сверки:

1. Требования к СПО — таблица 2 и эталон 008–020 комплекта `md_117` (модель пользователя, контуры `admin`/`public`, субъекты, СПБ.1–СПБ.14).
2. Методический документ ФСТЭК — [docs/fstek-methodology-2026.pdf](../fstek-methodology-2026.pdf) для состава реализации, усилений и событий, которые затем переносятся на испытания СПО.

Если таблица 2 СПО и методичка расходятся по применимости (класс К3/К2/К1 против уровня защищенности ПДн), для этого комплекта действует таблица 2 СПО.

| 001–007 | Введение | термины, общие положения, модель пользователя, выбор и реализация мер |
| 008–011 | ИАФ.1–ИАФ.4 | идентификация и аутентификация |
| 012–020 | УПД.1–УПД.9 | управление доступом |
| 021–025 | РСБ.1–РСБ.5 | регистрация событий |
| 026–030 | ЗВТ.1–ЗВТ.5 | защита веб-технологий |
| 031–033 | ЗПИ.1–ЗПИ.3 | защита API |
| 034 | АВЗ.1 | антивирусная проверка объектов СПО |

| 044–057 | СПБ.1–СПБ.14 | меры ГИС Санкт-Петербурга |

## Что исключено как не относящееся к СПО

Меры инфраструктуры и смежных технологий не входят в специальный набор и в этот комплект не включаются:

- ЗСВ, ЗКО, ЗЭП, ЗКУ, ЗМУ, ЗИВ, ЗБД, СОВ, МСЭ, ЗКС;
- АВЗ.2–АВЗ.4, ЗОО.2, ЗОО.4, ЗОО.6.

Их проверка относится к ОС, сети, почте, виртуализации, контейнерам, конечным и мобильным устройствам, а не к функциям разрабатываемого СПО.

Автопроверки Linux-хоста (`./check_all.sh --measure …`) остаются в `fstek_audit/checks/` и описаны отдельно в [docs/methodology](../methodology/README.md). Они не заменяют испытания СПО.

## Параметры в интерфейсе администратора безопасности

По **СПБ.5** (в исходном промпте ошибочно указан как СПБ.4) каждая мера явно перечисляет параметры, которые выносятся в интерфейс администратора безопасности. Ослабление методических минимумов/максимумов из интерфейса недопустимо.

**СПБ.4** в требованиях к СПО — это формат журналов для ЦОУ ИБ АПК-БГ, не интерфейс настроек.
