**Цель**: Для аутентификации процессов СПО используются уникальные специальные учетные записи с минимально необходимыми привилегиями.

**Регламентирование**: Не предъявляются.

Описание реализации, действий и результатов при испытаниях:

| Требование | Действие | Результат |
|------------|----------|-----------|
| Процессы СПО не используют общие или пользовательские учетные записи и имеют минимально необходимые привилегии. | Открыть на example.ru/admin перечень технологических учетных записей процессов; попытаться назначить процессу привилегии администратора безопасности; вызвать API процесса с чужой УЗ. | Успех: У каждой процесса своя УЗ; избыточные привилегии отклонены; чужая УЗ не принимается. |

**Параметры безопасности в интерфейсе администратора безопасности (СПБ.5):**

Все перечисленные параметры должны быть доступны для оперативного редактирования из интерфейса СПО (`example.ru/admin`) администратору безопасности, с ограничениями, исключающими ослабление политик безопасности ниже значений, установленных методикой и требованиями к СПО (мера СПБ.5).

- перечень технологических учетных записей процессов;
- минимальные права каждой технологической УЗ.
