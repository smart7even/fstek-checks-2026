**Цель**: Обеспечение защиты СПО от несанкционированного доступа в случаях, когда субъект доступа оставляет активный сеанс (сессию) без контроля.

**Регламентирование**: В эксплуатационной документации для СПО должны быть определены:

- значения допустимого времени бездействия для различных категорий пользователей;
- порядок реализации автоматического блокирования сеанса при превышении допустимого времени бездействия;
- порядок восстановления работы субъекта доступа после блокирования сеанса;
- порядок регистрации событий превышения установленного оператором допустимого числа неуспешных попыток разблокирования доступа.

**Параметры безопасности в интерфейсе администратора безопасности (СПБ.5):**

Все перечисленные параметры должны быть доступны для оперативного редактирования из интерфейса СПО (`example.ru/admin`) администратору безопасности, с ограничениями, исключающими ослабление политик безопасности ниже значений, установленных методикой и требованиями к СПО (мера СПБ.5).

- допустимое время бездействия для категорий пользователей;
- режим реакции: блокирование сеанса и (или) завершение сеанса;
- число неуспешных попыток разблокирования, после которого сеанс завершается.

Требования к усилению:

1) В информационной системе должно осуществляться завершение сеанса доступа после превышения установленного оператором времени бездействия (неактивности) субъекта доступа;
2) В информационной системе должно осуществляться завершение сеанса доступа после превышения установленного оператором числа неуспешных попыток разблокирования сеанса доступа.
