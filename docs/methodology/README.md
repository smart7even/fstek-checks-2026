# Методические документы автопроверки Linux-хоста

По одному файлу на каждую меру (скрипт) из `fstek_audit/checks/`.
Формат — как у [ИАФ.1](IAF/7.1. ИАФ.1 Идентификация пользователей.md): цель, регламентирование, таблица «Требование / Действие / Результат», усиления, таблица классов.

Испытания **специального программного обеспечения** (не скриптов) собраны отдельно: [docs/spo-wiki](../spo-wiki/README.md). Там нумерация с 008 = ИАФ.1, исключены меры, не относящиеся к СПО, и указаны параметры интерфейса администратора безопасности (СПБ.5).

Источник требований: [fstek-methodology-2026.pdf](../fstek-methodology-2026.pdf) (ФСТЭК России, 12.04.2026).

Проверка полноты:

```bash
bash tests/methodology_docs.sh
```

Автопроверка Linux-хоста для меры:

```bash
./check_all.sh --measure <КОД> --class K3
./check_all.sh --measure <КОД> --class K2 --with-enhancements
```
