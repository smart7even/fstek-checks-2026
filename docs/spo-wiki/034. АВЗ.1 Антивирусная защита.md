**Цель**: Обеспечение антивирусной защиты объектов, обрабатываемых СПО: обнаружение вредоносного ПО во входящих файлах и реагирование на обнаружение.

**Регламентирование**: В эксплуатационной документации для СПО должны быть определены:

- порядок проверки файлов, поступающих в СПО из внешних источников;
- действия по реагированию при обнаружении вредоносного ПО;
- порядок обновления баз признаков вредоносных программ, используемых СПО.

Описание реализации, действий и результатов при испытаниях:

| Требование | Действие | Результат |
|------------|----------|-----------|
| СПО проверяет объекты, поступающие от пользователей и внешних источников (загрузка файлов, вложения, интеграционные потоки), средствами антивирусной защиты. | Загрузить на example.ru/admin и, если предусмотрено, на example.ru/public тестовый индикатор вредоносного ПО и допустимый файл. | Успех: Индикатор отклонен либо помещен в карантин; допустимый файл принят после проверки. |
| При обнаружении выполняются определенные действия реагирования, администратор безопасности уведомляется, событие регистрируется в РСБ. | Открыть на example.ru/admin журнал РСБ и сведения о реагировании после загрузки индикатора. | Успех: Объект недоступен для запуска; администратор уведомлен; событие зарегистрировано. |
| Базы признаков обновляются в установленном порядке; после обновления выполняется проверка объектов, находящихся в СПО. | Открыть на example.ru/admin сведения о дате баз и факте проверки после обновления. | Успех: Базы актуальны; проверка после обновления выполнена и зарегистрирована. |

**Параметры безопасности в интерфейсе администратора безопасности (СПБ.5):**

Все перечисленные параметры должны быть доступны для оперативного редактирования из интерфейса СПО (`example.ru/admin`) администратору безопасности, с ограничениями, исключающими ослабление политик безопасности ниже значений, установленных методикой и требованиями к СПО (мера СПБ.5).

- признак обязательной проверки загружаемых и передаваемых файлов;
- действие при обнаружении (отклонение, карантин);
- канал уведомления администратора безопасности;
- сведения об актуальности баз признаков.

Требования к усилению:

1) централизованное управление антивирусной защитой;
2) проверка в масштабе времени, близком к реальному, объектов из внешних источников при загрузке, открытии или исполнении.
