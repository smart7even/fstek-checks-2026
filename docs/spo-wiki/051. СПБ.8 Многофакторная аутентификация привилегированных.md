**Цель**: Доступ внутренних привилегированных пользователей реализован через многофакторную аутентификацию с российскими криптографическими алгоритмами без ЕСИА.

**Регламентирование**: Не предъявляются.

Описание реализации, действий и результатов при испытаниях:

| Требование | Действие | Результат |
|------------|----------|-----------|
| **Субъект: Администратор, администратор безопасности.**<br><br>Вход только по паролю на example.ru/admin не допускается. | Войти привилегированным пользователем только по паролю. | Успех: Доступ не предоставлен. |
| ЕСИА не принимается для привилегированного доступа. | Войти привилегированным пользователем через ЕСИА. | Успех: Вход через ЕСИА не принят для этой роли. |
| Вход с предусмотренным российским криптографическим фактором допускается. | Войти с многофакторной аутентификацией на российских криптоалгоритмах (без ЕСИА). | Успех: Вход осуществлен. |
| **Субъект: Привилегированный с личного мобильного устройства.**<br><br>Удаленный доступ с личного мобильного устройства не допускается (ИАФ.3). | Открыть example.ru/admin привилегированной УЗ с личного мобильного устройства. | Успех: Доступ не предоставлен. |

**Параметры безопасности в интерфейсе администратора безопасности (СПБ.5):**

Все перечисленные параметры должны быть доступны для оперативного редактирования из интерфейса СПО (`example.ru/admin`) администратору безопасности, с ограничениями, исключающими ослабление политик безопасности ниже значений, установленных методикой и требованиями к СПО (мера СПБ.5).

- состав факторов для привилегированных пользователей;
- запрет ЕСИА для привилегированного доступа;
- используемые российские криптографические алгоритмы.
