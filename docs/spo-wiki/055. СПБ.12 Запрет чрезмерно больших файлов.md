**Регламентирование**: Не предъявляются.

Описание реализации, действий и результатов при испытаниях:

| Требование | Действие | Результат |
|------------|----------|-----------|
| **Субъект: Внутренний непривилегированный.**<br><br>Файл больше установленной квоты отклоняется на example.ru/admin. | Загрузить файл больше установленного максимума. | Успех: Файл не принят; хранилище не исчерпано; событие зарегистрировано. |

| Ослабление максимума ниже безопасного порога из интерфейса недопустимо, если порог задан в ОРД. | Попытаться задать неограниченный размер файла в параметрах СПБ.5. | Успех: Неограниченное значение отклонено либо требует отдельного обоснования, не снимающего защиту от заполнения хранилища. |

- максимальный размер принимаемого файла;
- действие при превышении (отклонение).
