# 10.6. ЗСВ.6 Ограничение программной среды в среде виртуализации

**Скрипт:** `fstek_audit/checks/ZSV/ZSV_06.sh`

Цель: Блокирование несанкционированного запуска программного обеспечения в среде виртуализации.

Регламентирование: Не предъявляются.

Описание реализации, действий и результатов при испытаниях:

| Требование | Действие | Результат |
|------------|----------|-----------|
| Должно обеспечиваться выявление запуска компонентов программного обеспечения хостовой операционной системы и средства виртуализации, не включенных в перечень компонентов, разрешенных для запуска. | 1. Открыть перечень компонентов, разрешенных для запуска на хостовой ОС и в средстве виртуализации (политика SELinux/AppArmor/PARSEC, профиль libvirt/qemu).<br><br>2. Запустить на хосте гипервизора компонент, не включенный в перечень (испытательный бинарный файл вне белого списка).<br><br>3. Открыть журнал аудита/СЗИ (`ausearch`, `journalctl`, журнал PARSEC, AVC/AppArmor) и найти факт запуска. | 1. Успех: Перечень разрешенных компонентов задан.<br><br>2. Успех: Запуск неразрешенного компонента выполнен в испытательных целях.<br><br>3. Успех: Запуск компонента, не включенного в перечень, выявлен. |
| Указанные меры реализуются за счет применения в информационной системе встроенных в средства виртуализации и (или) хостовые операционные системы механизмов безопасности. | Повторить запуск неразрешенного компонента при включенных профилях AppArmor/SELinux (или PARSEC на Astra Linux) для libvirt/qemu. | Успех: Выявление запуска обеспечивается встроенными механизмами средства виртуализации и (или) хостовой ОС. |
| Условия: У Системы К1.<br><br>Должна обеспечиваться блокировка запуска компонентов программного обеспечения хостовой операционной системы и (или) средства виртуализации, не включенных в перечень программного обеспечения, разрешенного для запуска в среде виртуализации. | 1. Убедиться, что механизм ограничения включен в режиме блокировки (PARSEC mode enforce/strict, `security_driver` selinux/apparmor в `/etc/libvirt/qemu.conf`).<br><br>2. Попытаться запустить на хосте виртуализации компонент, не включенный в перечень разрешенного ПО. | 1. Успех: Режим блокировки включен.<br><br>2. Успех: Запуск неразрешенного компонента заблокирован. |
| Автопроверка Linux-хоста | `./check_all.sh --measure ЗСВ.6 --class K3`<br><br>`./check_all.sh --measure ЗСВ.6 --class K2 --with-enhancements` | Зафиксированы вердикты PASS/FAIL/SKIP/NA по локальным признакам (AppArmor/SELinux/PARSEC, режим блокировки неразрешенного ПО). SKIP не считается провалом испытания СПО. |

Требования к усилению:

1) должна обеспечиваться блокировка запуска компонентов программного обеспечения хостовой операционной системы и (или) средства виртуализации, не включенных в перечень программного обеспечения, разрешенного для запуска в среде виртуализации.
