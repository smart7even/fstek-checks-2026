# 18.5. ЗБД.5 Ограничение уровней сигналов беспроводного доступа

**Скрипт:** `fstek_audit/checks/ZBD/ZBD_05.sh`

Цель: Обеспечение невозможности (затруднения) доступа к точкам беспроводного доступа из-за пределов контролируемой зоны.

Регламентирование: Не предъявляются.

Описание реализации, действий и результатов при испытаниях:

| Требование | Действие | Результат |
|------------|----------|-----------|
| Должны применяться точки беспроводного доступа, имеющие возможность настройки уровня мощности сигнала. | На AP/контроллере открыть параметр мощности передатчика (`tx_power` в hostapd/`iw dev wlan0 set txpower`, эквивалент контроллера) и убедиться, что значение задается администратором, а не фиксировано производителем без возможности изменения. | Успех: Уровень мощности сигнала настраивается штатными средствами AP/контроллера. |
| Должно обеспечиваться ограничение уровней сигналов точек беспроводного доступа. Значения уровней сигналов должны устанавливаться с учетом физических границ информационной системы (сегментов) с целью обеспечения минимального уровня сигнала на физических границах. | 1. По плану контролируемой зоны задать `tx_power`/эквивалент контроллера так, чтобы покрытие обслуживало помещения ИС и было минимальным на границе.<br><br>2. Выполнить радиообследование: на внутренней точке покрытия и на физической границе/снаружи контролируемой зоны замерить RSSI (`iw dev wlan0 scan`, анализатор спектра).<br><br>3. С клиента за границей контролируемой зоны попытаться ассоциироваться с корпоративным SSID (WPA2-Enterprise). | 1. Успех: Мощность ограничена с учетом границ сегментов/контролируемой зоны.<br><br>2. Успех: На границе уровень сигнала минимален (покрытие внутри помещений сохраняется, вне зоны устойчивый сигнал отсутствует).<br><br>3. Успех: Доступ к точке доступа из-за пределов контролируемой зоны невозможен либо существенно затруднен. |
| Автопроверка Linux-хоста | `./check_all.sh --measure ЗБД.5 --class K3` | Зафиксированы вердикты INFO/SKIP/NA: параметры `tx_power`/`country_code`/`ieee80211d` сами по себе не подтверждают ограничение покрытия. Радиообследование и уровень сигнала на границе контролируемой зоны локально не классифицируются как PASS. SKIP не считается провалом испытания СПО. |

Требования к усилению:

1) должен осуществляться мониторинг уровней сигналов точек беспроводного доступа;
2) должна быть составлена карта покрытия сигналами точек беспроводного доступа помещений информационной системы (сегментов информационной системы), размещение точек беспроводного доступа и уровень мощности их сигналов должны быть определены с учетом карты покрытия;
3) должна осуществляться фильтрация частотного диапазона передачи данных точки беспроводного доступа для исключения несанкционированного доступа к информации, передаваемой по беспроводному каналу.
