# Security Policy

Скрипты предназначены для локального аудита конфигурации Linux-систем и не должны выполнять изменяющие операции.

Если найдено поведение, которое меняет настройки системы, создает пользователей, меняет права, останавливает службы или передает чувствительные данные наружу, это считается дефектом безопасности проекта.
